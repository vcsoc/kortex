# Architecture decisions

1. Independently implement from the specification. Do not access or translate GitNexus implementation. Owner policy is proprietary/closed-source/private with no use grant to others; packages remain private and public publication is prohibited.
2. Use the prescribed workspace boundaries and a shared serde domain model. SQLite bundled with FTS5 and immutable committed snapshots is the persistence authority. A held advisory file lock serializes writers. Readers load an active generation snapshot.
3. Use native Tree-sitter grammar crates (Rust, Python, JavaScript, TypeScript, Go), not regex parsing. Resolve conservatively: same-name matching alone is not sufficient for cross-file calls.
4. Keep offline core independent of HTTP/UI and embeddings. No repository code is executed. Git inspection uses the installed Git executable with explicit argument arrays, no shell interpolation or hooks; document this runtime requirement.
5. Cache serialized immutable per-file facts keyed by content/parser/config versions. Re-resolve globally on updates initially: conservative correctness over speculative partial invalidation. This is a documented performance limitation.
6. Rust toolchain pinned to the installed 1.99.1. Dependency versions locked in Cargo.lock; dependency provenance/audit must be reviewed before distribution.
7. Native notify events feed a bounded nonblocking queue and debounce bursts. Periodic reconciliation catches missed/overflow events; no event stream is assumed lossless. Queue overflow cannot allocate unbounded memory.
8. MCP uses the actual rmcp SDK rather than a custom protocol approximation. Incoming lines are bounded before SDK buffering, tool workers/deadlines are bounded, and encoded response budgets account for both text and structured payloads. Graphs are not independently truncated into invalid node/edge sets.
9. First-party Rust forbids unsafe code through workspace lints. Bundled SQLite, Tree-sitter and native watcher FFI remain dependency review boundaries. Local development archives can be built without granting any release license; public packaging is unconditionally disabled under the current owner policy.
10. Automated auditing rejected the initial bundled SQLite and MCP SDK versions. Upgrade to rusqlite 0.42.0/libsqlite3-sys 0.40.0 and rmcp 3.9.0 instead of suppressing advisories (including SDK optional-feature advisories). Local cargo-deny then passes all four checks. Owner license and full distribution/provenance approval remain distinct gates.
11. Direct event testing showed missing FSEvents delivery on the local host; periodic reconciliation had masked it in the earlier journey. Use notify's native macOS kqueue backend, retain native delivery assertions, and preserve periodic fallback. Kqueue's per-file descriptor scaling requires larger-workspace benchmarking; Linux/Windows use their native backends and await platform evidence.
12. Owner explicitly prohibits access/use/distribution by others until they say otherwise. LICENSE is a restrictive proprietary notice, not a permissive grant. First-party Cargo packages inherit publish=false and the notice; web package is private. Public packaging refuses even with legacy approval variables. All hosted jobs require a private repository, and native artifact validation requires additional owner approval. No remote settings, collaborators, hosted jobs, uploads or releases were changed/launched.
13. Owner approved React + TypeScript + Cytoscape.js for the real optional explorer. Assets must be locally bundled, authorization must remain in public API handlers, and the UI must not introduce telemetry, CDN requests or implicit source uploads.
