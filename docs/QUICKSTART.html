Kortex quick start

Private development software. Full production acceptance is open. The default ignore-policy loader has a known confinement issue; do not use this build on untrusted repositories.

Kortex builds a local, source-derived index. Treat the index as sensitive, and verify its findings against source and tests.

1. Initialize a trusted project

kortex init /path/to/project

This may create project configuration and an AGENTS.md section and may build an index. It does not configure an MCP client.

2. Search and inspect

kortex --repo /path/to/project query authentication
kortex --repo /path/to/project context path/to/file.rs:Symbol
kortex --repo /path/to/project impact path/to/file.rs:Symbol

Replace the example paths and symbols with real ones. See kortex --help and each command's --help for current options.

3. Connect an agent

In a supported agent's MCP settings, explicitly add the installed Kortex executable with argument mcp. Consult that agent's own configuration documentation. Kortex does not automatically modify agent settings.

This page works offline. No remote scripts, fonts, analytics, models or services are loaded.
